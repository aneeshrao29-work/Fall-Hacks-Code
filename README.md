What is our application about?

Inspiration

We were inspired by existing AI code assistants, but we wanted to add our own spin. Oftentimes, AI assistants feel stiff and unspecific in their help; we wanted to address the problem.

What it does

JepiTheGenie analyzes code and points out mistakes in the program. When not in use, Jepi becomes a cute addition to your desktop screen. You can customize Jeppi by choosing the accessories or the personas it takes on.

Challenges we ran into

We ran into problems while making sure all group members have and can run the project on their laptops.

Accomplishments that we're proud of

We are proud of having created a working prototype.

What we learned

We learned to fix errors and debug. We also learned more about project development and implementation.
